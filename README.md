# FM app

Фронтенд FM сети на Vue.js.
Реализует все основные протоколы децентрализованных эхоконференций.

```bash
cd fm-app

# Установка зависимостей
npm install

# Запуск в dev режиме
npm run dev

# Сборка для production
npm run build
```

### Тесты
```bash
cd fm-app
npm test
npm run test:run  # без watch-режима
```
